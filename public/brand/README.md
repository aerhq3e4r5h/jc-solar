# GridAnchor logo

The mark is an anchor that is also the "power on" symbol: the anchor's
curved arms are the power symbol's open ring, and its shank is the power
stroke rising through the gap, topped with the anchor's crossbar and ring.
It says what the business does: when the grid lets go, your power stays
anchored.

| File | Use |
| --- | --- |
| `gridanchor-logo.svg` / `.png` | Main logo on white or light backgrounds |
| `gridanchor-logo-on-dark.svg` / `.png` | On dark backgrounds |
| `gridanchor-logo-stacked.svg` / `.png` | Square spaces: social profiles, signage, stickers |
| `gridanchor-mark.svg`, `gridanchor-mark-1024.png` | The mark alone: profile pictures, app icon |
| `gridanchor-mark-ink.svg` / `-white.svg` | One colour, no tile: engraving, vinyl cutting, embroidery |

Colours: signal yellow `#FFC414`, graphite `#1E1E1C`, white.
Type: Archivo Expanded ExtraBold (Google Fonts, SIL Open Font License).
The wordmark in the SVG files is outlined, so it looks the same without the font.

Give the logo clear space of at least half the mark's width on every side,
and don't use it smaller than 24 px high on screen (the favicon uses a
simpler mark without the top ring). Regenerate the files with `scripts/brand/`.
