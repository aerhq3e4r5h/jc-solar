# JC Solar logo

The mark is the "power on" symbol drawn as a sun: the ring is the sun, the
power stroke rises out of it as the noon ray, and the six short rays leave
the bottom open, as if the sun sits on the horizon. It says what the
business does: the power comes on, and stays on.

| File | Use |
| --- | --- |
| `jc-solar-logo.svg` / `.png` | Main logo on white or light backgrounds |
| `jc-solar-logo-on-dark.svg` / `.png` | On dark backgrounds |
| `jc-solar-logo-stacked.svg` / `.png` | Square spaces: social profile banners, signage, stickers |
| `jc-solar-mark.svg`, `jc-solar-mark-1024.png` | The mark alone: profile pictures, app icon, favicon |
| `jc-solar-mark-ink.svg` / `-white.svg` | One colour, no tile: engraving, vinyl cutting, embroidery |

Colours: signal yellow `#FFC414`, graphite `#1E1E1C`, white.
Type: Archivo Expanded ExtraBold (Google Fonts, SIL Open Font License).
The wordmark in the SVG files is outlined, so it looks the same without the font.

Give the logo clear space of at least half the mark's width on every side,
and don't use it smaller than 24 px high on screen (the favicon uses a
simpler mark without rays). Regenerate the files with `scripts/brand/`.
